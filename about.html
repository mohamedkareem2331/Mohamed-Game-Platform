💻 Windows PC Installation Guide

All downloadable games in the builds section are packaged using PyInstaller into self-contained 64-bit Windows executables:

  1. Click the Download PC button on any game page or library card.
  2. Save the `.exe` file to your preferred folder (e.g., Desktop or Games).
  3. Double-click the executable to launch immediately. No Python or runtime installation needed!
  4. If Windows SmartScreen appears on first run, click More info → Run anyway.
