# Artwork and dependencies

Dungeon is an original game inspired by classic turn-based dungeon crawlers.
The reference screenshot was used for genre direction. No code or artwork
from Shattered Pixel Dungeon is included.

The local assets.pak uses selected PNGs from the Craftpix packs supplied in
this workspace: Dungeon bulids, mobs and the movement, sword weapens,
Shield and Amulet, and Bow and Crossbow. tools/prepare_assets.py records the
exact source paths. Original files and their license notices are preserved.

Craftpix terms: https://craftpix.net/file-licenses/
These assets are not covered by the code's MIT license. The source repository
excludes the original packs and assets.pak. Distribute the built game using
the rights applicable to your downloaded packs; do not offer the raw artwork
as a separate asset download. The game has an original drawn-art fallback,
so a public source checkout remains playable without the Craftpix pack.
